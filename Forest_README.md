# 🌳 Forest Fires in Brazil – Exploratory Data Analysis (EDA)


## 📌Overview

This project performs **Exploratory Data Analysis (EDA)** on the **Forest Fires in Brazil** dataset to uncover **trends**, **seasonal patterns**, and **regional variations** in fire occurrences between **1998 and 2017**.


---

## 📂 Project Structure

├── Forest_Fires_Brazil_EDA.html # Jupyter Notebook exported as HTML (EDA results)  

├── forest_fires_brazil.csv # Dataset file used for analysis  

├── images/ # Graphs and visualizations  

└── README.md # Project documentation  

---



## 🔍 EDA Highlights

From the **`Forest_Fires_Brazil_EDA.html`** report:

- **Peak Fire Months:** August, September, and October  

- **Most Affected States:** Pará, Mato Grosso, and Maranhão  

- **Yearly Trends:** Significant peaks around **2004** and **2007** 

- **Seasonal Impact:** Fire incidents rise sharply during the **dry season** 

- **Monthly Variation:** Fires tend to be minimal during **February–April**
